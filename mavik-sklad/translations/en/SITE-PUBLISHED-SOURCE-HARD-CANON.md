# ENGLISH TRANSLATION — HARD SOURCE CANON

Updated: 2026-08-17
Status: **HARD CANON / OVERRIDES ALL OLDER SOURCE RULES**

## USER RULE

For English translation of books on mavik.name:

**The ONLY authoritative source text is the canonical Ukrainian text actually published on the pages of mavik.name.**

No translation sentence may be created from:
- chat memory;
- model memory;
- File Library DOCX/DOC/TXT manuscript;
- old warehouse manuscript;
- old translation;
- synopsis, status, checkpoint or canon summary;
- guessed continuation;
- reconstructed or paraphrased source;
- any assistant-written bridge, connective phrase, clarification or addition.

## ZERO-ADDITION RULE

- No invented text.
- No added explanations.
- No added descriptions.
- No added dialogue.
- No added connective passages.
- No filling gaps from context.
- No improving or expanding the original.
- No translating a passage unless its Ukrainian source has first been physically retrieved from the canonical mavik.name publication.

The task is translation only, not co-writing.

## SOURCE OF TRUTH

For each book, use its canonical Ukrainian publication on mavik.name, primarily the public reader page under `/books/<slug>/read/` and its site-generated text representation when it is demonstrably the same published text.

If any manuscript, File Library file, warehouse copy, old English file or checkpoint differs from the live published Ukrainian site text, **the published mavik.name text wins** unless the user explicitly designates a new source later.

## EXISTING ENGLISH FILES

Existing English translation files are recovery artifacts only until checked against the canonical site publication. They must not be assumed correct merely because they already exist.

For `The Sculptor`, all currently saved English files must be treated as **UNVERIFIED / NOT CANONICAL FOR PUBLICATION** until checked line-by-line against the Ukrainian text published on mavik.name.

No unverified file may be deployed or used as the source for new translation.

## REQUIRED WORKFLOW

For every new block:
1. Retrieve the exact next contiguous Ukrainian passage from mavik.name.
2. Preserve its exact position/chapter boundary.
3. Translate only that retrieved text.
4. Do not add anything not present in the retrieved Ukrainian source.
5. Save the English translation physically.
6. Read it back.
7. Record the exact site-source marker/position used.
8. Mirror to the safety branch.

If the canonical site source cannot be retrieved, **stop translation at the last verified site-source point**. Do not improvise.

## PRIORITY

This file overrides any older instruction that allows use of File Library manuscripts or warehouse manuscripts as translation source.

User command establishing this hard canon:
`Жодних вигадок! Жодного додавання власного тексту! Тільки переклад з канонічних текстів, оригінали яких на сторінках сайту! Це жорсткий канон!`

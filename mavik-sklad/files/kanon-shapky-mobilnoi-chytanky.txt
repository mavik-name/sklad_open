1. БАЗОВИЙ КАНОН
- Поточна structural/functional база сайту — R192.
- Шапка звичайної мобільної екранної читанки зберігає чинну компактну структуру, компонування і функції.
- Не перебудовувати шапку без окремого прямого рішення користувача.
- Історичні посилання на R184/R186 пояснюють походження дизайну, але НЕ є базою для нової роботи.

2. «ЗМІСТ»
- Пункт/кнопка «Зміст» у лівому меню шапки працює як toggle.
- Перше натискання відкриває зміст.
- Повторне натискання на той самий контроль закриває зміст.
- Відкриття/закриття змісту не повинно ламати або перебудовувати шапку.

3. КНОПКА «НАЗАД» У HEADER — НЕ ДОДАВАТИ
- Старе рішення з малим золотим трикутником `◀` перед `A−` було скасоване.
- Не повертати його в reader header.
- Загальносайтова навігація `← Назад / Back`, додана в R190–R192, є окремим in-content navigation pattern і не є частиною цієї шапки.
- Чисту text-only сторінку для Chrome Read Aloud не засмічувати цією UI-навігацією.

4. ПОВЕРНЕННЯ ДО СТОРІНКИ КНИГИ
- У мобільній читанці функцію повернення до landing page поточної книги забезпечує чинний нижній mobile dock/«Будиночок».
- «Будиночок» веде на `/books/<slug>/` поточної книги.
- Це не причина додавати дубль у header.

5. ТЕМА
- Півмісяць залишається перемикачем теми.
- Сам півмісяць — золотий; оформлення узгоджене з іншими чорними/золотими controls.

6. CHROME READ ALOUD
- Звичайна reader page залишається основною читанкою.
- Окрема чиста text-only версія для Chrome повинна містити текст одразу в HTML і не повторювати меню/reader controls.
- Не замінювати це JS `speechSynthesis` як основним механізмом.

7. МОВИ
- Reader UI має бути language-aware через єдиний multilingual core.
- Не використовувати Google Translate/translator UI.
- Не створювати окрему копію reader framework для English.

8. ПЕРЕВІРКА ПІСЛЯ ЗМІН
- header не отримав старий `◀`;
- «Зміст» toggle працює;
- тема працює;
- `Будиночок` веде на сторінку поточної книги;
- in-content `← Назад / Back` не ламає header;
- text-only Chrome page лишається чистою;
- mobile touch test виконується після реальної зміни reader UI.

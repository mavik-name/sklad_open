- `/about/`;
- `/announcements/`;

Модель:
- редаговані блоки: hero/заголовок, текст, rich text, цитата, зображення, кнопка, відступ;
- системний динамічний блок сторінки є окремим locked-блоком: його можна переставити, але не можна випадково видалити;
- публічний HTML використовує контрольні marker-зони `BEFORE / SYSTEM / AFTER`, тому динамічний каталог/фільтри/інші системні компоненти не серіалізуються в редактор як довільний HTML;
- перед збереженням доступний структурний preview;
- перед кожним збереженням автоматично зберігається попередній state конкретної сторінки;
- є відновлення попередньої версії.

### 2. `/books/`: актуалізація вступу

Прибрано застарілу згадку про «Соціальну» як твір у режимі тестового читання.

Чинний вступ:
> Твори українською: завершені публікації з повними веб-читанками. Читалка запам’ятовує місце, де ти зупинився, і підтримує режим з музикою. Для завершених релізів також доступний EPUB, а на сторінках творів — перевірені зовнішні публікації, якщо вони є.

### 3. Boss → «Анонси»: повторне виправлення вертикального зсуву

### 4. Boss → «Пошта»

Додано внутрішній поштовий клієнт:
- конфігурація IMAP/SMTP;
- тест з'єднання;
- список папок;
- останні 50 листів;
- читання;
- відповідь;
- створення нового листа;
- завантаження вхідних вкладень;
- одне вихідне вкладення до 12 MB;
- резервне посилання на Cityhost webmail.

Безпека:
- поштовий пароль не зашитий у PHP;
- поштовий пароль відсутній у ZIP;
- mail config/password не входять у глобальний state export;
- конфіг зберігається тільки на сервері в `_site-state/mail-client.json`;
- ключ зберігається окремо в `_site-state/mail-client.key`;
- пароль шифрується Sodium secretbox, а за відсутності Sodium — OpenSSL AES-256-GCM;
- файли поштових секретів не входять до managed files релізу.

Вхідна пошта потребує активного PHP IMAP extension на хостингу. SMTP-відправлення реалізоване через socket/STARTTLS і не залежить від PHP IMAP.

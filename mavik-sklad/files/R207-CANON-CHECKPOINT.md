## Що канонічно входить у R207

1. Надійне додавання книги через Boss із rollback: при помилці не лишається напівстворена/незареєстрована книга.
2. Явні режими книги:
   - `Завершена · створити EPUB`;
   - `Бета · без EPUB`.
3. Перехід Бета → Завершена створює EPUB; Завершена → Бета прибирає EPUB.
4. EPUB генерується всередині дозволеної папки сайту (`/_site-state/tmp/...`), без системного `/tmp`, що усуває Cityhost `open_basedir` conflict.
5. Постійний реєстр жанрів:
   - можна додавати нові жанри;
   - жанр зберігається для наступних книг;
   - genre state входить у Boss state export/import.
6. Boss підтримує безпечні малі overlay-патчі для подальшого контентного наповнення без повного CORE-релізу:
   - patch-manifest;
   - base release validation;
   - SHA-256 validation;
   - backup/rollback;
   - файли поза патчем не видаляються.
7. Мовна навігація не має примусового «замка»: прямий URL має пріоритет. Відкриття `/` не повинно самовільно перекидати в `/en/`, а `/en/` лишається English locale.

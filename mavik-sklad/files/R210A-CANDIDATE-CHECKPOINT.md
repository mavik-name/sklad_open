## Авторське рішення, яке реалізує R210A

Автор прямо встановив архітектурне правило:

> Усі сторінки, які не є частиною функціонального каркаса сайту, мають бути звичайними сторінками, що редагуються як контент через Boss. Це правило однаково діє для української та всіх міжнародних мовних версій.

Тому інформаційні сторінки не повинні мати власну жорстко зашиту CORE-розмітку/контент. CORE відповідає за маршрут, багатомовний renderer, навігацію та службову логіку; текст, фото й композиція сторінки є контентним станом.

## Що змінено

### 1. Звичайні сторінки відокремлено від каркаса

Із системного drag&drop page-builder прибрано:
- `Автор` (`/about/`);
- `Приватність` (`/privacy/`);
- `Права` (`/copyright/`);
- `Платформи` (`/platformy/`).

Вони мігрують у звичайний багатомовний content-state Boss.

У каркасному конструкторі лишаються тільки сторінки, де є невіддільна автоматична функціональна частина:
- `Книги`;
- `Що почитати`;
- `Анонси`;
- `Теми`.

### 2. Єдина модель для міжнародних версій

Звичайна сторінка має один slug/сутність і окремі locale-поля для кожної активної мови: publish flag, title, SEO description та body HTML.

Нові мовні пакети автоматично отримують поля для цих сторінок у Boss; текст не зашивається в CORE. Непідготовлена мовна версія лишається неактивною до публікації.

Generic language placeholder generator не має права перезаписувати сторінку, яку вже керує ordinary-page renderer.

### 3. Сторінка «Автор» одразу приведена до нормального вигляду

`/about/` — звичайна сторінка.

Український погоджений текст перенесено в content-state без втрат.
Портрет `/images/author/viktor-makarchuk.jpg` більше не є жорстким окремим системним блоком:
- він вставлений безпосередньо в body сторінки;
- desktop: ліворуч, ширина приблизно 240 px, текст реально обтікає фото справа;
- mobile: float вимикається, фото центрується над текстом;
- фото можна надалі змінити/переставити/видалити через редактор звичайної сторінки без нової CORE-збірки.

У редактор звичайних сторінок додано вставлення зображення з варіантами: ліворуч з обтіканням, праворуч з обтіканням, по центру.

### 4. Міграція стану

Додано `_site-admin/state-defaults/static-pages.json`.
На першому завантаженні R210A ordinary pages одноразово додаються в `site-core.json`, не перезаписуючи вже існуючу сторінку з тим самим id/slug.

Старі записи `about/privacy/copyright/platformy` автоматично прибираються зі state системного page-builder; функціональні `books/discover/announcements/themes` зберігаються.

### 5. Захист міжнародного routing

Під час генерації locale core існуючий `/<locale>/.htaccess` більше не перезаписується. Це зберігає спеціальні redirect rules, зокрема наявний EN redirect `announcements/kod-lehendy → /en/books/kod-lehendy/`.

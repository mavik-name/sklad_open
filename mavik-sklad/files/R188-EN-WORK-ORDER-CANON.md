## ЕТАП 2 — CONTENT OVERLAYS ПІСЛЯ ВСТАНОВЛЕННЯ R188

Після базового R188 англійське наповнення додається без перескладання всього сайту:
- одна книга = один overlay-ZIP, якщо це зручно;
- кілька книг = один комплектний overlay-ZIP;
- окремими overlays можуть іти Blog / Announcements / About;
- англійські обкладинки;
- англійські EPUB;
- виправлення конкретного перекладу або метаданих.

Кожен content overlay має містити лише потрібні файли з правильними шляхами, проходити перевірку власного складу та не затирати runtime-data (`/_site-state/`, `analytics/data`, `reactions/data` тощо).

Для контентних overlays бажаний неймінг із прив’язкою до бази, наприклад:
`R188-EN-CONTENT-001-<slug>.zip`
або
`R188-EN-CONTENT-SET-001.zip`.

Контентний overlay **не є новим повним релізом сайту**. Новий повний номер релізу потрібен лише для наступної структурної/функціональної зміни або якщо користувач прямо цього вимагає.

## Вміст

1. **01_ІНСТРУКЦІЯ_ПРОЄКТУ.md** — компактні обов’язкові правила для інструкцій проєкту ChatGPT: контроль часу, місця, погоди, логіки, сусідніх глав, редагування та форматування.
2. **02_КАНОН_РОМАНУ.md** — погоджені сюжетні положення, персонажі та структура організації; чітко відокремлено авторські рішення від робочих варіантів.
3. **03_ХРОНОЛОГІЯ_ДОСЛІДЖЕННЯ.md** — паралельні шкали документальної історії і художньої альтернативи, посилання та точки для перевірки.
4. **04_ВІДКРИТІ_ПИТАННЯ.md** — усе, що не слід визначати без автора.

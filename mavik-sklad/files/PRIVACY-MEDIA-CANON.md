# PRIVACY MEDIA — ЖОРСТКИЙ КАНОН

Дата: 2026-08-18
Статус: **HARD CANON**

## Головне правило

Приватні фото, відео, кадри з відео, селфі, портрети та будь-які інші матеріали, за якими можна відтворити зовнішність автора/користувача, **НЕ є загальною медіатекою проєкту**.

Їх не можна автоматично повторно використовувати в інших сторінках, блогах, обкладинках, анонсах, промоматеріалах, релізах чи ілюстраціях лише тому, що вони вже були надані в чаті або колись використані.

## Дозвіл завжди локальний

Якщо автор прямо дозволив використати приватне фото/відео для конкретної задачі, цей дозвіл діє **тільки для цієї конкретної задачі/зображення/публікації**.

Наприклад: дозвіл використати зовнішність автора в ілюстрації до одного блогу не дає дозволу використовувати її в інших блогах.

Для нового використання потрібен новий прямий дозвіл автора.

## За замовчуванням

Якщо прямого дозволу немає:
- не використовувати приватні фото/відео автора;
- не робити похідні портрети автора;
- не переносити його зовнішність у згенеровані сцени;
- не включати приватні кадри до public release assets;
- для публічних ілюстрацій використовувати неперсональні/generated visuals, що відповідають змісту тексту.

## Видалення

Якщо приватне зображення було використано ширше, ніж дозволено:
1. негайно зняти всі зайві public bindings;
2. замінити їх неперсональними зображеннями;
3. прибрати superseded private-derived files із release manifest;
4. при наступному deploy видалити ці файли з live-сайту штатним obsolete-file cleanup;
5. залишити тільки ті використання, на які був конкретний прямий дозвіл.

## Поточне явне виключення

Станом на 2026-08-18 автор прямо дозволив використати свою зовнішність **лише для ілюстрації до блогу `А що тут, власне, читати?`** (`shcho-tut-vlasne-chytaty`).

Цей дозвіл не поширюється на інші блогові записи чи інші публічні матеріали.

## Робочий контроль

Перед кожним використанням особистого фото/відео поставити питання:

**Чи є прямий дозвіл автора саме на це конкретне використання?**

Якщо ні — не використовувати.

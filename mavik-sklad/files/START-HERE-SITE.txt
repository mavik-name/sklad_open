============================================================
АРХІТЕКТУРНИЙ КАНОН
============================================================

- один багатомовний core;
- одна Boss-адмінка;
- одна модель даних;
- language packs/config, не окремі копії сайту;
- українська — коренева версія без префікса;
- інші мови — префікси типу `/en/`;
- жодного Google Translate / translator UI / translator fallback;
- explicit URL / ручний вибір мови має пріоритет над saved/browser language;
- browser autodetect лише fallback;
- нативні мовні кнопки лишаються для ручного вибору;
- меню та сторінки підтримують drag & drop;
- кількість книг на головній задається окремо для desktop і mobile;
- універсальна `← Назад / Back` є в полі внутрішніх сторінок, не в головному меню;
- чисту text-only сторінку для Chrome Read Aloud не засмічувати UI;
- великі повні релізи використовують multipart ZIP deploy через Boss.

## 2026-08-17 — Boss → «Пошта»: IMAP/SMTP

Статус: **ЗАКРИТО В R210**.

R209 спочатку залежав від PHP extension `imap`. У R210 додано автоматичний backend:
- якщо PHP IMAP доступний — використовувати його;
- якщо ні — вбудований TLS IMAP через `stream_socket_client`.

Cityhost:
- сервер `mx1.cityhost.com.ua`;
- IMAP 993 SSL/TLS;
- логін — повна email-адреса;
- SMTP — налаштування скриньки.

На живому Cityhost TLS-з’єднання встановлювалося одразу. Початкова `AUTHENTICATIONFAILED` була спричинена обліковими даними/логіном; після введення коректної повної email-адреси користувач підтвердив: **«Працює!»**.

Пошта у Boss канонічно включає папки, список листів, читання, відповідь, новий лист, вкладення та тест IMAP/SMTP. Пароль не входить у release/state export.

## 2026-08-17 — Desktop Boss → «Анонси»: вертикальний зсув action-блоку

Статус: **ЗАКРИТО У КАНОНІЧНОМУ R210**.

Історія:
- у R208 перша спроба не прибрала візуальний зсув;
- користувач надав скріншот, який показав, що вся права колонка дій сиділа вище відносно нижньої лінії `причина + Зберегти причину`;

- mobile action-блок переходить на повну ширину без штучного зсуву.

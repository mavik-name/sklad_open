1. ОДНА КНИГА = ОДНА СТОРІНКА
- Книга завжди лишається одним book object і однією canonical book page `/books/<slug>/`.
- placement/status `Бібліотека / Анонси` визначає лише, де вона показується.
- Анонс НЕ створює окремий тип сторінки або renderer.
- При `Анонси → Бібліотека` не створювати сторінку, обкладинку, опис чи metadata заново.

2. ОБКЛАДИНКА
- Сторінка книги показує поточну обкладинку з даних самої книги/Boss.
- Анонс використовує ту саму обкладинку.
- Заміна обкладинки у book object повинна автоматично відбитися на book page, cards і relevant metadata.

3. РОЗМІЩЕННЯ / АНОНС
- При створенні книги автор обирає `Бібліотека` або `Анонси`.
- Статус можна змінювати у редагуванні книги в обидва боки.
- `Опис для анонсу` — окреме редаговане поле; якщо воно порожнє, можна використати короткий опис книги.
- Книга зі статусом `Анонси` не показується як опублікована в каталозі Books/home books block, але має ту саму canonical book page.

4. АУДІО / ЧИТАННЯ
- Не додавати окрему застарілу піктограму `Динамік` на landing page книги.
- Chrome Read Aloud працює через reader/text-only flow.
- Mobile `Читати` = текст; `Слухати` = explicit listen mode.

5. «КАВА» / SUPPORT
- Українська book page може використовувати чинний Privat24/QR support layer.
- Не повинно бути зайвого/подвійного обрамлення coffee control.
- Для неукраїнських мов українські Privat24/QR не показувати; international support бере дані з provider-agnostic config.

6. «ПОДІЛИТИСЬ»
- Share зберігає чинну функцію поширення книги.
- Public label: `Поділитись`.
- Не створювати дублюючі share controls без потреби.

7. РЕАКЦІЯ «СПОДОБАЛОСЬ»
- Публічний напис: `Сподобалось`.
- `Зачепило` не використовувати як user-facing label.
- Якщо технічний key у даних має іншу назву, не ламати його механічним перейменуванням без перевірки залежностей.

8. НАВІГАЦІЯ «НАЗАД»
- На внутрішній сторінці `Назад` — перший пункт global public navigation.
- Не дублювати його окремим старим backbar або reader-header контролом.

9. МОВИ
- Сторінка книги є частиною єдиного multilingual core.
- UI/service labels беруться з language pack.
- Не створювати окремий English book-page framework.
- Якщо English book content ще не готовий, не підміняти його машинним перекладом.

10. ПЕРЕВІРКА ПІСЛЯ ЗМІН
- canonical URL книги не залежить від placement;
- обкладинка береться з book data;
- announcement ↔ library round-trip не втрачає page/cover/description/metadata;
- audio/reader flow не дублюється;
- coffee/support відповідає активній мові;
- share працює;
- user-facing реакція = `Сподобалось`;
- `Назад` не дублюється;
- static audit + real mobile smoke після UI-правок.

MAVIK.NAME — ЖОРСТКИЙ КАНОН СТОРІНКИ КНИГИ
Оновлено: 16.08.2026
Статус: АКТУАЛЬНИЙ ВУЗЬКИЙ КАНОН ПОВЕРХ R192

Перед зміною сторінки книги читати:
- `mavik-sklad/START-HERE.txt`;
- `mavik-sklad/files/START-HERE-SITE.txt`;
- `mavik-sklad/releases/CANON.md`;
- цей файл.

1. ОДНА КНИГА = ОДНА СТОРІНКА
- Книга завжди лишається одним book object і однією canonical book page `/books/<slug>/`.
- placement/status (`books` / `announcements`) визначає лише, де вона показується у каталогах.
- Анонс НЕ створює окремий тип сторінки або окремий renderer.
- При `announcement → books` не створювати сторінку, обкладинку, опис чи metadata заново.
- `Код легенди` зараз саме такий приклад: canonical page `/books/kod-lehendy/`, placement `announcements`.

2. ОБКЛАДИНКА
- Сторінка книги показує її поточну обкладинку з даних самої книги/Boss.
- Не вшивати окремий hardcoded шлях лише для анонсу.
- Заміна обкладинки у book object повинна автоматично відбитися на цій сторінці й у відповідних cards/meta.

3. ПІКТОГРАМА «ДИНАМІК»
- Стару окрему піктограму «Динамік» на landing page книги не повертати.
- Окремі старі audio-pages не є канонічним механізмом.
- Chrome Read Aloud працює через reader/text-only flow, а не через повернення старого «Динаміка».

4. «КАВА» / SUPPORT
- Українська book page може використовувати чинний Privat24/QR support layer.
- Не повинно бути зайвого/подвійного обрамлення coffee control.
- Для неукраїнських мов українські Privat24/QR не показувати; international support бере дані з provider-agnostic config R192.

5. «ПОДІЛИТИСЯ КНИГОЮ»
- Share зберігає чинну функцію поширення книги.
- Канонічне місце: окремий центральний елемент під основною reading action і над реакцією `Сподобалось`.
- Не повертати стару пару «Динамік / Поділитися».

6. РЕАКЦІЯ «СПОДОБАЛОСЬ»
- Публічний напис: `Сподобалось`.
- `Зачепило` не використовувати як user-facing label.
- Якщо старий технічний key існує у даних, не ламати його механічним перейменуванням без перевірки залежностей.

7. НАВІГАЦІЯ «НАЗАД»
- На внутрішній book page є загальносайтова ненав’язлива `← Назад / Back` у полі контенту, не в main menu.
- Спочатку працює як browser history back, а за відсутності корисної history має безпечний fallback у відповідний розділ.
- Не дублювати її в reader header.

8. ANNOUNCEMENT STATE
Коли книга має placement/status `announcements`:
- вона не показується як опублікована у каталозі Books/home books block;
- показується в Announcements;
- canonical page лишається `/books/<slug>/`;
- замість недоступних publish-actions показується коректний статус/повідомлення;
- для `Код легенди` формулювання: рукопис передано у видавництво **на розгляд**; не називати прийнятим або виданим.

9. МОВИ
- Сторінка книги є частиною єдиного multilingual core.
- UI/service labels беруться з language pack.
- Не створювати окремий English book-page framework.
- Якщо English book content ще не готовий, не підміняти його машинним перекладом.

10. ПЕРЕВІРКА ПІСЛЯ ЗМІН
- canonical URL книги не залежить від placement;
- обкладинка береться з book data;
- старого `Динаміка` немає;
- coffee/support відповідає активній мові;
- share працює;
- user-facing реакція = `Сподобалось`;
- `← Назад / Back` працює й не дублює меню/header;
- announcement ↔ books round-trip не втрачає page/cover/description/metadata;
- static audit + real mobile smoke після UI-правок.

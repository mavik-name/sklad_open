# НЕПОРУШНИЙ АЛГОРИТМ СПІВПРАЦІ НАД РОМАНАМИ

Статус: **UNIVERSAL / HARD CANON / AUTHOR APPROVED**  
Дата фіксації: 2026-08-30

Це правило діє **для всіх романів і великих художніх творів Віктора без винятку**, незалежно від жанру, теми, проєкту чи окремого сюжетного канону.

Воно може бути змінене, призупинене або скасоване **лише прямим рішенням Віктора**. Асистент не має права самостійно послаблювати, переосмислювати або ігнорувати цей алгоритм через зручність, новий формат роботи чи локальні правила конкретного твору.

## Обов’язковий цикл роботи

Для кожної нової глави:

1. **Анонс / задум глави.**  
   Спочатку коротко подати автору, що саме має відбутися в главі, її функцію, ключову зміну, важливі сюжетні та причинно-наслідкові вузли. Не писати повну главу до погодження.

2. **ОК / корекція автора.**  
   Автор підтверджує задум словом «ОК» або вносить зміни. Усі зміни автора стають пріоритетними для цієї глави й мають бути враховані до написання повного тексту.

3. **Повна глава.**  
   Після погодження написати **одну повну главу**, а не уривки, пробні шматки чи часткові версії.

4. **Файл DOCX.**  
   Видати цю главу окремим DOCX згідно з універсальним технічним каноном: Arial 11 pt, міжрядковий інтервал 1,5, стандартний абзацний відступ, вирівнювання ліворуч; сині Heading 1/2/3 для рівнів КНИГА / ЧАСТИНА / ГЛАВА.

5. **Аналіз / рецензія.**  
   Після написаної глави або після погодженого блоку глав провести потрібний редакторський аналіз, перевірку логіки, ритму, канону, фактичної точності та, коли це передбачено роботою над конкретним романом, незалежну рецензію.

6. **Лише потім — наступна глава.**  
   Не перескакувати вперед і не писати наступну главу автоматично, доки попередній етап не завершено або автор прямо не наказав інакше.

## Додаткове правило

Якщо під час роботи над конкретним романом локальний канон суперечить цьому алгоритму, **перемагає цей універсальний алгоритм**, якщо тільки Віктор прямо не скасував або не змінив його для конкретного випадку.

Коротка формула:

**анонс / задум → ОК або корекція автора → повна глава → DOCX → аналіз / рецензія → наступна глава.**

Це правило вважається непорушним до нового прямого рішення автора.

# Forum_Mavik_One

Канонічний пакет форуму, наступник тестового 0.9.1. Дата: 2026-09-08.

## Встановлення поверх чинного форуму
Зробіть резервну копію поточного каталогу та storage/forum.sqlite. Розпакуйте ZIP у корінь forum.mavik.name поверх файлів. Не видаляйте storage/forum.sqlite, storage/sessions, storage/social-config.php, assets/avatars або власні файли assets/ads. Архів не містить бази, сесій, тестових акаунтів чи завантажених користувацьких аватарів. Автоматичні зміни схеми додаткові; чинні дані зберігаються. Відкритий/закритий режим не перемикається.
Для нового встановлення: PHP 8.1+ з PDO SQLite, mbstring, GD, fileinfo, OpenSSL; Apache з AllowOverride та mod_rewrite. Відкрити install.php, створити свій акаунт адміністратора, після встановлення видалити install.php. Для Nginx потрібно окремо заборонити доступ до app/ і storage/ та виконання коду в assets/avatars/; .htaccess там не діє.

## Підключення Google на звичайному хостингу
У файловому менеджері відкрийте storage/social-config.example.php, зробіть копію з назвою social-config.php у тій самій папці. Вставте client_id та client_secret із вашого JSON між одинарними лапками у відповідні порожні рядки. Збережіть. JSON завантажувати не потрібно. storage закритий для HTTP через .htaccess, сам PHP-файл також захищений від прямого запуску. Перед внесенням секретів перевірте, що /storage/social-config.example.php не відкривається у браузері (403/404). Ключі не додавайте на GitHub. При наступних оновленнях зберігайте storage/social-config.php. Змінні середовища, якщо вони вже налаштовані, мають пріоритет. Для роботи Google потрібен cURL. Кнопки з’являються після заповнення обох значень; реальний вхід слід перевірити на домені.

## Склад релізу
Пошук тем і повідомлень; відповіді, цитування та гілки; згода з правилами; аватари; категорії та модерація; 30 днів входу від останнього відвідування. Активне меню золоте, лінія 1px лише при наведенні/фокусі. Кнопка створення теми у категорії з автоматичним вибором розділу. Ширина MaVik 1120px, оригінальний логотип. Теги відкривають пошук, окремої системи присвоєння тегів немає.

## Оновлення рекламного модуля та хедера
В Адмінка → Реклама можна завантажити JPG/PNG/WebP до 5 МБ або вказати URL картинки; файл перевіряється та перетворюється у WebP. HTML-код працює в sandbox iframe без доступу до сторінки форуму. Google має окремий режим. Завантажені банери зберігаються в assets/ads, їх потрібно залишати при оновленні. Висота хедера 88px desktop / 72px mobile, прозорість як на материнському сайті. Прибрано дубль пошуку, додано каву на всіх сторінках. Адміністратор бачить кнопку Адмінка → /admin/ (форум); кнопка «Адмінка сайту» всередині панелі веде на https://mavik.name/boss/. Мобільне меню відцентроване. в блоці привітання — власне фото, ім’я та Профіль. Зелена крапка: остання активність протягом 5 хвилин, оновлюється під час переходів; це не постійне онлайн-з’єднання.

## Банер UNIVERSE
Під час першого показу рекламного модуля після оновлення один раз встановлюється власний банер assets/ads/universe.png, посилання https://mavik.name/books/universe/. Місця: головна та форма нової теми. Обкладинка показується у природних пропорціях, ширина 300px (не обрізається до 300x600). Наступні зміни/вимкнення через Адмінка → Реклама не перезаписуються. Google не активований; можливий на головній у відкритому режимі після налаштування облікового запису та необхідної згоди відвідувачів.

## Безпека та SEO
Додано CSRF на вхід адміністратора, ліміт 20 спроб за 15 хвилин з IP для локального входу/реєстрації, HttpOnly/SameSite cookies, ізольовані сесії, заборону показу помилок PHP відвідувачам, захисні HTTP-заголовки. Обмеження стосується REMOTE_ADDR: за проксі потрібна перевірка його налаштування на хостингу. Службові сторінки noindex, публічні canonical/description, sitemap.php з видимих категорій і тем. У maintenance — 503/noindex/robots block, sitemap також 503. Виправлена сумісність пошуку з PHP 8.5.

Живий сервер не оновлювався; SMTP/Google OAuth/реальний AdSense на ньому не перевірені. Піксельна тотожність усіх сторінок початковим малюнкам не заявляється.

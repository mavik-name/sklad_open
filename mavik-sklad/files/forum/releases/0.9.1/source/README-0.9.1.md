# Forum MaVik 0.9.1 — виправлення після тесту

- Виправлено сторінку категорії: назва та автор у широкій колонці, кількість відповідей і дата окремо. На mobile метадані переходять під назву. Власні CSS-класи більше не успадковують шестиколонкову сітку головної.
- Форум, шапка і вміст звужені до канону материнського сайту: 1120px desktop; 920px на проміжних ширинах; мобільна оболонка до 640px із внутрішніми полями 16px.
- Маленький PNG логотипа замінено оригінальним assets/brand/mavik-mvv-gold.svg з R300. Знак займає 42px desktop / 40px mobile без зайвих полів; посилання веде на головну форуму.
- Прибрано нижню плаваючу каву; стрілка догори розташована праворуч.
- Реєстрація у профілі допису: підпис та дата YYYY-MM-DD на окремих рядках.
- Полегшено пропорції сторінки теми: заголовок, аватари, метадані, кнопки й цитати. Фон використовує чисте фото без намальованих кнопок.
- Оновлено CSS cache version до 0.9.1, щоб браузер завантажив виправлення після заміни файлів.

Оновлення: розпакувати ZIP у корінь встановленого форуму поверх 0.9. Не видаляти storage/forum.sqlite та assets/avatars. Архів не містить SQLite або тестових акаунтів. Змін схеми БД порівняно з 0.9 немає. Для переходу з 0.8 див. ../0.9/build-0.9/README-UPDATE-0.9.md на складі.

Перевірки: 38 перевірок категорій (320–1889px, довгі назви, переходи, головна) та 36 перевірок ширини/логотипа/шапки (320–1889px), 10 перевірок плаваючих кнопок і 6 перевірок реєстрації; PHP lint. Скриншоти і JSON у qa/.

# Forum MaVik 0.9.1 — виправлення після тесту

- Вхід зберігається 30 днів від останнього відвідування, включно з перезапуском браузера. Сесії ізольовані у storage/sessions; не видаляйте цей каталог під час оновлення. Після переходу на нове сховище потрібно один раз увійти повторно. Вихід і блокування облікового запису припиняють доступ.
- Застосовано новий зразок подачі списку тем: аватар, тема й автор/дата створення; статистика; аватар, автор і дата останнього повідомлення. Кольори MaVik збережені.
- Додано admin/ads.php: вимкнено / власний банер за URL / AdSense за Publisher ID і Slot ID, 300x250 або 300x600, вибір місць. Власний банер доступний біля форми нової теми та на головній; Google лише на головній у відкритому режимі. Mobile переносить блок під форму. Налаштування зберігаються в settings, без зміни схеми. Реклама за замовчуванням вимкнена. Перевірено збереження, desktop/mobile розміщення та вимкнення.
- Теги головної стали посиланнями на реальний пошук відповідних слів у темах і повідомленнях; підкреслення у складених тегах перетворюються на пробіли. Це пошукові ярлики, окремої системи присвоєння тегів темам поки немає.
- Типографіка меню з материнського R300: Georgia, desktop 14px/1 (13px на проміжній ширині), mobile 24px/1.12; активний пункт 700.
- Кнопка категорії вирівняна праворуч, із відступами 20px зверху та 24px до таблиці; оновлено ключ кешу CSS.
- На сторінках категорій додано «+ Створити тему» з попереднім вибором поточної категорії у формі.
- Фон головної замінено чистим фото без намальованої кнопки під справжньою «Створити тему».
- Прибрано дубль входу в адмінку: у шапці «Профіль», у привітанні адміністратора «Адмінка форуму».
- Виправлено сторінку категорії: назва та автор у широкій колонці, кількість відповідей і дата окремо. На mobile метадані переходять під назву. Власні CSS-класи більше не успадковують шестиколонкову сітку головної.
- Форум, шапка і вміст звужені до канону материнського сайту: 1120px desktop; 920px на проміжних ширинах; мобільна оболонка до 640px із внутрішніми полями 16px.
- Маленький PNG логотипа замінено оригінальним assets/brand/mavik-mvv-gold.svg з R300. Знак займає 42px desktop / 40px mobile без зайвих полів; посилання веде на головну форуму.
- Прибрано нижню плаваючу каву; стрілка догори розташована праворуч.
- Реєстрація у профілі допису: підпис та дата YYYY-MM-DD на окремих рядках.
- Полегшено пропорції сторінки теми: заголовок, аватари, метадані, кнопки й цитати. Фон використовує чисте фото без намальованих кнопок.
- Оновлено CSS cache version до 0.9.1, щоб браузер завантажив виправлення після заміни файлів.

Оновлення: розпакувати ZIP у корінь встановленого форуму поверх 0.9. Не видаляти storage/forum.sqlite та assets/avatars. Архів не містить SQLite або тестових акаунтів. Змін схеми БД порівняно з 0.9 немає. Для переходу з 0.8 див. ../0.9/build-0.9/README-UPDATE-0.9.md на складі.

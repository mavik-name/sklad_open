# Візуальний канон і стан приймання

Користувач вимагає 100% відповідності трьом наданим PNG. Вони є каноном, не вільним натхненням. Виняток останнього уточнення: НЕ використовувати взірцевий логотип із mobile PNG; у mobile потрібен оригінальний MaVik.

Статус: візуальне приймання НЕ завершене. Не називати цей пакет фінальним або 100% відповідним канону.

Реалізовано темну таблицеподібну композицію, золоту систему, компактні категорії/теми, праву колонку desktop, перебудову mobile, профільну колонку поста, золоті лапки зі світло-сірою підкладкою. Coffee/arrow — незмінені надані SVG; їхні власні контури збережено, CSS-кругів немає. Оригінальна маска надана користувачем. Favicon/app icons та payment assets взято з локальної канонічної R300.

У assets/hero-reference.png і topic-reference.png збережено копії PNG: CSS використовує лише ділянки фонової сцени, а не малює скриншот замість інтерактивного форуму. Mobile landscape так само показує нижню художню смугу референсу. Всі кнопки, списки, пошук і пости — реальні HTML/дані SQLite.

Ще звірити / довести:
- Точну типографіку, оптичні розміри логотипа, позиції меню й дрібні піктограми.
- Mobile hero та пропорції панелей щодо вихідного референсу; його phone-frame і системний status bar не є частиною вебсторінки.
- Footer: базовий текстовий канон містить інший набір текстів/посилань, ніж desktop PNG; він поки збережений разом із mobile художньою смугою.
- Відображення даних із реальної БД (довгі назви, багато постів, реальні профільні фото). QA-скриншоти містять тестові дані, не вигадані лічильники зі взірця.

Перевірені ширини: 1448px desktop homepage, 1672px desktop topic, 390px mobile homepage/topic; додатковий screenshot homepage на 592px. PNG-результати у qa. Порівняння людиною та доведення геометрії до 100% залишається release gate.

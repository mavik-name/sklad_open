# forum.mavik.name 0.9 — тестовий кандидат

База: оригінальний forum_mavik_test_build_0.8.zip від користувача. Основний ZIP передається користувачу; sklad_open зберігає копію та весь стан для продовження.

Зміни:
- Реальний Unicode-пошук назв, початкових текстів тем і відповідей; релевантний фрагмент, сторінки, виключення прихованих категорій/тем/постів.
- reply_to_post_id, батьківський preview, стабільні якорі, «Показати гілку», окремі «Відповісти» / «Цитувати», атрибуція та золоті лапки.
- Обов’язкова серверна згода з правилами й дата прийняття; сесії заблокованих користувачів припиняються.
- Завантаження 512×512 WebP, повернення маски, видалення аватара адміністратором. Підключувані Google/Telegram, захист state/PKCE/HMAC, окрема згода соціальної реєстрації, контрольоване прив’язування identities, оновлення фото. Live-перевірка потребує реальних ключів.
- Окремий last_activity_at, pinned зверху; редагування старих постів не змінює дату активності.
- Drag&drop, ↑/↓, редагування іконки/назви/опису, видимість, захист непорожньої категорії й перенесення тем.
- Скарги, модерація постів, підписки у БД. Email-розсилки не реалізовані.
- Maintenance 503/noindex/robots, preview-пароль з відкликанням сесії після зміни, підтвердження публічного відкриття.
- Канонічні SVG, favicon/app icons, desktop coffee dialog, mobile support link, desktop/mobile CSS.

68 перевірок успішні + lint та браузерна перевірка. SQLite у ZIP відсутня. Візуальні 100% НЕ підтверджені; див. VISUAL-STATUS.md. Пакет призначений для тесту, не для неконтрольованого публічного запуску.

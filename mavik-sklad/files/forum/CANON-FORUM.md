## 2. Головна форуму
- Hero — одна композиція, не окрема велика картинка.
- Книги/чашка в hero без примусових написів, якщо вони не виглядають органічно й натурально.
- Пошук + `Створити тему` на одному горизонтальному рівні на desktop.
- Категорії — одна компактна таблицеподібна панель, не набір великих окремих карток.
- Рядок категорії: піктограма, назва+опис, кількість тем, відповідей, остання активна тема, стрілка.
- Права колонка: welcome / останні обговорення / правила / популярні теги.
- `Останні теми` — компактні рядки: піктограма, тема/теги, відповіді, перегляди, останній автор+аватар+час.
- Теми ранжуються: pinned зверху, далі за останньою реальною активністю. Нова відповідь піднімає тему. Просте редагування старого поста — ні.

## 4. Сторінка теми — ЗАТВЕРДЖЕНИЙ КАНОН
- Верх: breadcrumbs + великий serif-заголовок + короткий опис + підписатися / відповісти.
- Пост має ліву профільну колонку та основний текст праворуч на desktop.
- В кожному пості: `Відповісти` та `Цитувати`.
- На mobile структура перебудовується без втрати зручності.
- Профільна зона: аватар, ім'я, статус/метадані делікатно.
- Внизу: навігація попередня/наступна тема там, де доречно.

### Цитати
- Великі золоті лапки — головний акцент.
- Ледь видима світло-сіра підкладка (`rgba(255,255,255,.04-.06)` як орієнтир).
- Текст цитати світло-сірий/кремовий, не золотий.
- Автор цитати + перехід до оригінального повідомлення.
- Не вставляти весь довгий пост без потреби; у reply context використовувати короткий фрагмент.

### Ланцюжок розмови
- Кожна відповідь може мати `parent_post_id` / `reply_to_post_id`.
- Показувати: кому відповідає, короткий фрагмент, лінк до оригіналу.
- Додати `Показати гілку` для конкретного ланцюжка.
- Не робити безмежну вкладеність зі зміщенням вправо.

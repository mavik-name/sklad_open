## ЖОРСТКИЙ КАНОН ПІСЛЯ R203 — CODE FREEZE

Після канонізації R203 подальша звичайна робота із сайтом виконується **лише контентними PATCH/OVERLAY-пакетами БЕЗ ЗМІНИ КОДУ R203**.

Це означає:
- не змінювати PHP;
- не змінювати JavaScript;
- не змінювати CSS;
- не змінювати Boss-функціонал;
- не змінювати шаблони/rendering architecture;
- не змінювати PWA/service worker/manifest logic;
- не змінювати навігаційний engine;
- не змінювати SEO/indexing engine;
- не робити прихованих «покращень», рефакторингу чи оптимізації CORE під виглядом контентного patch.

Дозволені PATCH/OVERLAY:
- книги та переклади;
- EPUB;
- обкладинки та ілюстрації;
- музика/медіа;
- блог і контентні сторінки;
- контентні дані/метадані;
- згенеровані публічні індекси й SEO-артефакти, які створюються чинними механізмами без зміни їхнього коду.

**Будь-яка зміна коду заборонена без нового прямого рішення користувача, яке явно скасовує/послаблює цей freeze.** Не створювати новий CORE-реліз самостійно.

## Головний канон синхронізації

Контентні зміни через Boss або patch мають лишати узгодженими public state і search state, де релевантно: navigation/internal links, sitemap, robots/noindex, canonical, hreflang, structured data, IndexNow та внутрішній SEO-аудитор. Це робиться чинними можливостями R203, без модифікації коду.

## Захищена поведінка R203

- mobile: доступне встановлення MaVik як PWA;
- mobile: доступна аудіочиталка з однією центральною кнопкою `▶ Читати ↔ ⏸ Пауза`, tap-to-start і Screen Wake Lock;
- desktop: аудіочиталка не ініціалізується;
- desktop: кнопка `▶ Слухати` на сторінках книг не показується;
- desktop: MaVik install UI не ініціалізується;
- QR донату збільшується лише в межах самого блоку, без окремого QR-frame/modal;
- literal iframe/frame/frameset у збірці відсутні;
- Boss-редагування книги — звичайний inline-блок, не fixed drawer/frame;
- порядок книг зберігається серверно й відбивається в live manifest/public rebuild;
- для книг в анонсах є редаговане поле причини статусу;
- мобільне меню без нумерації;
- `/_site-state/` не перезаписується deploy/patch.

## КАВА / МІЖНАРОДНА ПІДТРИМКА

Українська підтримка лишається через чинний Privat24/QR-механізм.

Для неукраїнських версій:
- Privat24 та українські QR не показуються;
- міжнародна підтримка provider-agnostic;
- конфігурація: `assets/app/international-support.json`;
- у R192 `enabled=false`, тому порожній support-блок не показується;
- західну систему підтримки можна додати малим data/config patch без перебудови core;
- дозволені public HTTPS links та copyable public values;
- секретні API keys/tokens у public config не класти.

## MULTIPART DEPLOY

Multipart — канонічний механізм доставки великих повних релізів:

1. Частини одного релізу мають спільний set/release metadata.
2. Перша отримана частина лише зберігається у захищеному staging.
3. Живий сайт не оновлюється, доки немає всіх частин.
4. Boss підтримує порядок `PART-1 → PART-2` і `PART-2 → PART-1`.
5. Після появи всіх частин Boss перевіряє комплект і розгортає його як один повний реліз.
6. `/_site-state/` зберігається.
7. Створюється backup.
8. Після успішного deploy pending staging очищується.

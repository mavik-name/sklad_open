`Книги → Музика → Блог → Автор → Анонси → Вхід/Адмінка`.

Канонічний mobile-порядок:
`01 Книги → 02 Музика → 03 Блог → 04 Автор → 05 Анонси → 06 Вхід/Адмінка`.

Маршрути:
- Книги → `/books/`
- Музика → `/music/`
- Блог → `/blog/`
- Автор → `/about/`
- Анонси → `/announcements/`

Книжковий каталог на головній ЗБЕРЕЖЕНИЙ. Це важливий канон після помилкової спроби прибрати його. Внутрішній anchor домашнього книжкового блока — `#home-books`. Пункт меню `Книги` при цьому веде на канонічну бібліотеку `/books/`, а не на `/#books`.

Boss повинен і надалі керувати книжковими картками/порядком на головній і окремою сторінкою `/books/`.

## 6. ЧИТАНКА

Звичайна web-читанка є основною. Окремий `/read/audio/` не є канонічним способом Chrome Read Aloud; системний Chrome має читати звичайну читанку.

Mobile header:
- не перебудовувати без прямої команди;
- `Зміст` — toggle;
- старого малого трикутника `reader-back-mini` перед A− немає;
- повернення на сторінку книги винесене в нижній mobile dock через `Будиночок`.

Канонічний mobile dock:
`Помилка → Будиночок → ← → Закладка → → → Нота → Кава`.

Музичний режим тимчасово займає/перебудовує нижній простір згідно з актуальним reader CSS; після закриття стандартні controls повертаються.

Детальний канон шапки: `mavik-sklad/files/kanon-shapky-mobilnoi-chytanky.txt`.

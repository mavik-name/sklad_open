# forum.mavik.name — HANDOFF / CANON

Дата фіксації: 2026-09-08
Статус: активна розробка, перехід у нову гілку/чат після цього handoff.
Поточна база: `forum_mavik_test_build_0.8.zip`.
Rollback: `forum_mavik_test_build_0.7.zip`.
Наступна збірка: **0.9** (не латати 0.8 хаотично; робити контрольований patch/rebuild фронту + функціональні виправлення нижче).

## 1. Архітектура
- Публічний форум живе **повністю окремо** на `https://forum.mavik.name/`.
- PHP + SQLite. Форум самостійний: своя БД, сесії, користувачі, адмінка, логіка, storage.
- Основний сайт `mavik.name / R300` не працює напряму з SQLite форуму.
- У R300 достатньо пункту **«Форум»** в адмінці, що переводить на `https://forum.mavik.name/admin/`.
- У forum admin є посилання назад у адмінку основного сайту.
- Спільна адмін-сесія між сайтом і форумом на цьому етапі не потрібна.

## 2. Maintenance / закритий режим
- До публічного відкриття форум за замовчуванням закритий.
- Гість бачить делікатну ремонтну сторінку.
- HTTP 503 + `X-Robots-Tag: noindex, nofollow` + `meta robots=noindex,nofollow`.
- Sitemap до відкриття не публікувати.
- robots.txt у maintenance закриває форум; після відкриття автоматично переходить у нормальний режим.
- Адмін після входу бачить повний форум.
- Опційний окремий пароль тестового перегляду.
- В адмінці: увімкнути/вимкнути maintenance, змінити текст, задати/очистити пароль.
- Перед відкриттям форуму потрібне підтвердження.

## 3. Брендинг
- Форум є частиною одного «всесвіту» MaVik, без окремої форумної айдентики.
- Колористика, типографіка, хедер, меню, hover/active, футер — у стилі `mavik.name`.
- Темний/графітовий фон, тепле золото, кремово-сірий текст, делікатні лінії.
- Хедер напівпрозорий, з blur/градієнтом як на MaVik.
- Канон логотипу **1:1 як на сайті**: знак 40×40 px; `MaVik` 20 px; `МАКАРЧУК ВІКТОР` 10 px; ті самі відступи/пропорції.
- Клік по логотипу форуму → головна `forum.mavik.name`.
- Перехід на основний сайт — через глобальне меню.
- Використати той самий favicon / app icons, що й на mavik.name.

## 4. Меню
- Desktop: меню як на основному сайті, вирівняне вправо.
- Mobile: саме mobile-menu сайту, не стиснений desktop.
- Переходи: Книги, Музика, Блог, Автор, Анонси + Форум (активний).
- На основному mavik.name додати «Форум» → `https://forum.mavik.name/`.
- Внутрішня навігація форуму не дублює глобальне меню.

## 5. Ширина / геометрія
- Орієнтир — канон основного сайту (`.wrap` до 1480 px із полями), якщо живий R300 не змінено.
- Форум має бути щільним і делікатним, не розтягнутим.
- Desktop і mobile — два повноцінні стани однієї системи.

## 6. Головна форуму
Референс: `references/FORUM_HOME_REFERENCE.png`.
- Hero — одна композиція, не окреме гігантське фото.
- На книжках/чашці без написів, якщо неможливо зробити натурально.
- Пошук + «Створити тему» в одному рядку на desktop.
- Категорії — компактна таблицеподібна панель.
- «Останні теми» — компактні рядки з метаданими.
- Права колонка: welcome / останні обговорення / правила / теги.
- Footer — у стилі MaVik.

## 7. Категорії
В admin:
- drag&drop на desktop;
- ↑ / ↓ на mobile;
- редагувати;
- приховати / показати;
- видалити лише з підтвердженням;
- категорію з темами не видаляти одним кліком: спочатку перенести теми або приховати.

## 8. Сортування тем
- Закріплені — зверху.
- Далі за останньою активністю.
- Нова відповідь піднімає тему.
- Редагування старого поста тему не піднімає.
- Якщо відповідей немає — активність = дата створення.
- Те саме для «Останніх обговорень».

## 9. Пошук — BUG / must fix in 0.9
У 0.8 пошук не працює. У 0.9 зробити реальний пошук:
- по назвах тем;
- по текстах повідомлень;
- бажано SQLite FTS5, fallback на безпечний LIKE;
- результат: тема, фрагмент збігу, категорія, автор/дата, перехід до конкретного повідомлення.

## 10. Пости, відповіді, ланцюжки
- У кожному пості кнопка «Відповісти».
- Окрема дія «Цитувати».
- Кожна відповідь зберігає `reply_to_post_id` / `parent_post_id`.
- Не робити безмежну вкладеність сходинками.
- Показувати: кому відповідають + короткий фрагмент + перехід до оригіналу.
- Додати «Показати гілку» / механізм перегляду конкретного ланцюжка.
- Нижня навігація між темами — як у каноні.

## 12. Піктограми / плаваючі контролі
Канонічні файли:
- `assets/coffee.svg`
- `assets/arrow-up.svg`

Правила:
- без CSS-кружків, плашок, видимих фонів;
- сама SVG-графіка;
- невидимий touch-area ~44×44 на mobile лишається;
- категорійні піктограми — тонкі золоті, однакової оптичної ваги;
- у 0.8 частина піктограм невидима — BUG, виправити в 0.9.

Кава:
- Mobile: `https://mavik.name/support`.
- Desktop: те саме модальне вікно підтримки, як на MaVik (monobank / Privat24 / QR).
- Стрілка «догори» — canonical `arrow-up.svg`.

## 13. Аватари
- Завантажити/змінити/видалити свій аватар.
- JPG/PNG/WebP, оптимізація, зберігання локально.
- Можна взяти аватар із Google/Telegram; дія «Оновити з профілю».
- Стандартний аватар — надана маска анонімуса (`assets/default-avatar-anonymous-mask.zip`).
- В admin можна прибрати неприйнятний аватар.

## 14. Реєстрація / вхід
- email + password локально;
- Google + Telegram як identity providers; локальний `users` — головний запис;
- при реєстрації обов’язковий checkbox **«Я прочитав(ла) і погоджуюся з Правилами форуму»**;
- «Правила форуму» — активне посилання;
- без checkbox реєстрація не проходить;
- бажано записати `rules_accepted_at` і версію правил.

## 15. Правила форуму
Головний принцип: **Не ображати ближнього.**
Писати можна про все. Сперечатись можна. Критика, незгода, гостра дискусія — можна. Персональні образи, приниження, цькування — ні.
Далі стандартний мінімум: без спаму/нав’язливої реклами, шахрайства, публікації чужих персональних даних, незаконного контенту, масового дублювання/технічного засмічення. Модерація може приховати повідомлення, закрити тему або обмежити користувача при системних порушеннях.
